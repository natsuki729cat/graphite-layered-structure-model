# Graphite Layered Structure — 3D-Printable Model

グラファイト（黒鉛）の層状構造をそのまま手に取れる形にした、教育・展示向けの3Dプリントモデルです。
六角形のグラフェン層が **AB積層（Bernal積層）** で3層重なった構造を、実際の結晶データの比率で再現しています。

> GitHub上で `graphite.stl` を開くと、そのまま3Dプレビューで形を確認できます。

## The science / 構造について

- 層内の炭素原子は sp² 結合で六角形（ハニカム）ネットワークを作ります。C–C結合長は **1.42 Å**。
- 層と層の間隔は **3.35 Å**。モデルではこの比率（層間隔／結合長 ≒ 2.36）をそのまま使っています。
- AB積層では、2層目の原子の半分が1層目の原子の真上に来ます。その位置を細い縦棒でつないでいます（層間相互作用のイメージであると同時に、モデルを支える柱になっています）。
- 炭素原子＝球、層内の結合＝棒、というボール＆スティック形式です。

## Files / ファイル

| File | Description |
|---|---|
| `graphite.scad` | パラメトリックな OpenSCAD ソース（寸法・層数・球の大きさを変更可能） |
| `graphite.stl` | 印刷用STL（下記パラメータで生成済み） |

## Model parameters / モデルの寸法

- 結合長（層内）: 12 mm（= 1.42 Å をスケール）
- 層間隔: 約28.3 mm（= 3.35 Å、同スケール）
- 層数: 3層（ABA）
- 全体サイズ: 台座 約112 × 97 mm、全体の高さ 約85 mm
- 原子数: 110個（3層合計）

## Print settings / 印刷設定（目安）

- 方式: FDM（PLA推奨）
- ノズル: 0.4 mm、層高: 0.2 mm
- インフィル: 15–20 %
- サポート: **あり（ツリーサポート推奨）** — 横向きの結合棒と球の下側に必要です
- 台座がベッドに接する向きで、そのまま印刷できます

パラメータを変えたい場合は `graphite.scad` の先頭の数値を編集して、OpenSCADで再エクスポートしてください。
`$fn` を上げると球が滑らかになります（ファイルサイズも増えます）。
なお、このリポジトリの `graphite.stl` はファイルサイズ軽量化のため `$fn = 12` で生成しています。高精細版が欲しい場合は `$fn` を上げて再エクスポートしてください。
